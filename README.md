# Traffic Accident Analysis – Data Analytics Project

**Project Overview:** This project analyzes traffic accident data to understand the patterns and conditions associated with recorded accidents. The objective of this project is to perform data cleaning, exploratory data analysis (EDA), and data visualization using Python and data analytics tools.

---

**Dataset Information:**

* Dataset Name: Traffic Accident Dataset
* File Format: CSV
* Data Type: Structured data
* Number of Records: 10,000
* Key Columns:

  * Vehicle Name
  * Traffic Control Device
  * Weather Condition
  * Lighting Condition
  * Trafficway Type
  * Roadway Surface Condition
  * Road Defect
  * Crash Hour
  * Crash Day of Week
  * Crash Month

---

**Tools Used:**

* Python:

  * Pandas for data manipulation and analysis
  * NumPy for numerical calculations
  * Matplotlib for charts and visualizations
  * Seaborn for data visualization
  * Jupyter Notebook for analysis

---

**Analysis Performed:**

* Checked dataset structure, columns, and data types
* Checked for missing values and duplicate records
* Identified 4 duplicate records
* Converted categorical columns into category data types
* Converted numerical day values into weekday names
* Converted numerical month values into month names
* Analyzed accident patterns based on weather conditions
* Studied accident frequency by lighting conditions
* Analyzed accidents by road type and road surface condition
* Analyzed accident frequency by traffic control devices
* Studied accident patterns by hour, day, and month
* Used `groupby()` to analyze accidents by road type
* Created bar, line, pie, and scatter charts to visualize the data

---

**Key Insights:**

* Clear weather had the highest number of recorded accidents
* Daylight had the highest number of recorded accidents
* Non-divided roads had the highest number of recorded accidents
* Dry road surfaces had the highest number of recorded accidents
* Roads with no traffic controls had the highest number of recorded accidents
* 5 PM (17:00) had the highest number of recorded accidents
* Friday had the highest number of recorded accidents
* July had the highest number of recorded accidents

---

**Conclusion:** The analysis shows that traffic accidents in the dataset were frequently recorded under clear weather, daylight, dry road conditions, and on non-divided roads. The highest accident frequency was observed at 5 PM, on Friday, and during July. This project helped me improve my skills in data cleaning, exploratory data analysis, data grouping, and data visualization using Python, Pandas, NumPy, Matplotlib, and Seaborn.
